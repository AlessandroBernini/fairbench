# Discovered Models Directory

This directory contains markdown files generated by the weekly model discovery script
(`scripts/cron/discover_models.py`).

## Format

Each file follows the pattern: `new-models-YYYY-MM-DD.md`

```markdown
# New GGUF Models Discovered
**Generated:** 2026-10-25 00:00 UTC
**Models found:** 12

## Proposed additions to registry

| Name | Repo | Quant | Params | Context | Age | Downloads |
|------|------|-------|--------|---------|-----|-----------|
| `llama3.3-70b` | `meta-llama/Llama-3.3-70B-Instruct-GGUF` | `q4_k_m` | 70.0 | 131072 | 15d | 1,234,567 |
```

## How to use

1. Review the proposed models in the markdown file
2. Add valid models to `fairbench/registry.py`
3. Run `fairbench validate-registry` to check for outdated models
4. Commit changes and open a PR

## Automation

The discovery runs automatically every Sunday at 00:00 UTC via GitHub Actions.
New models are proposed as PRs to the `main` branch.
